# TalentAI n8n Phase 1 — v1.0.0

اولین Release تیمی TalentAI، مسیر کامل دریافت رزومه تا ثبت ارزیابی فنی قابل ممیزی را ارائه می‌کند.

## قابلیت‌ها

- دریافت رزومه PDF و استخراج پروفایل ساخت‌یافته؛
- اعتبارسنجی Profile Schema نسخه `1.0`؛
- ذخیره Extraction در PostgreSQL؛
- Grade Guide نسخه‌بندی‌شده برای `JAVA_BACKEND`؛
- پشتیبانی از Target Gradeهای تعریف‌شده در Guide؛
- Evidence Scoring با الزام Quote و Confidence؛
- محاسبه قطعی Overall Score و Dimension Floorها؛
- ثبت Assessment، Decision، Model، Prompt و Engine Version؛
- سه Workflow وابسته که در محیط منبع داخل Folder `TalentAI - Phase 1` نگه‌داری می‌شوند؛
- Migration، Seed، Query و اسکریپت‌های راه‌اندازی و اعتبارسنجی؛
- Bootstrap محلی یک‌مرحله‌ای با حفظ `.env` موجود؛
- تنظیم خودکار Editor و Form URL براساس `N8N_HOST_PORT`؛
- Runtime Permissionهای صریح برای Role محدود `talentai_app` و کنترل خودکار آن‌ها.

## Workflowها

1. `TAI-01 Resume Intake & Extraction v2`
2. `TAI-02 Grade Guide Resolver v1`
3. `TAI-03 Evidence Scoring & Deterministic Grade Engine v1`

## نصب

راهنمای کامل راه‌اندازی محیط جدید، Credentialها، Import Workflowها و تست End-to-End در `README.md` Repository قرار دارد.

Package ضمیمه Release فاقد Folder، Credential Reference، Pin Data، Static Data، API Key و داده رزومه است. Artifact به‌صورت Flat ساخته شده تا روی n8n Community قابل Import باشد. پس از Import باید Credentialهای PostgreSQL و OpenAI محیط مقصد به Nodeهای مرتبط اختصاص داده شوند.

در نصب تازه یا ارتقای Volume موجود، `scripts/apply-database.sh` باید پیش از Smoke Test اجرا شود تا Migration `V004` مجوزهای `SELECT/INSERT` لازم را روی هر سه جدول TalentAI اعمال کند.

## نسخه‌های آزموده‌شده

- n8n `2.36.8`
- PostgreSQL `18.6`
- `@n8n/cli` `0.16.0`

## محدودیت‌های شناخته‌شده

- Evidence Score توسط LLM تولید می‌شود و ممکن است بین اجراها کمی تغییر کند؛
- Decision پس از تولید Dimension Scoreها به‌صورت قطعی محاسبه می‌شود؛
- داده رزومه ادعای کاندید است و اعتبار بیرونی آن بررسی نمی‌شود؛
- Grade Guide این Release فقط برای `JAVA_BACKEND` آماده شده است؛
- Credentialها و Secretها باید در هر محیط به‌صورت محلی تنظیم شوند؛
- Package انتشار Folder را منتقل نمی‌کند؛ سه Workflow در Personal Project مقصد Import می‌شوند؛
- این Release برای MVP و Demo داخلی است و هنوز Production Hardening کامل ندارد.

## امنیت و حریم خصوصی

- از رزومه واقعی بدون مجوز برای Demo استفاده نکنید؛
- `.env`، API Key و فایل‌های `exports/private` را منتشر نکنید؛
- Package را پیش از Import در محیط مشترک با SHA-256 منتشرشده تطبیق دهید؛
- PostgreSQL و n8n محلی فقط روی `127.0.0.1` منتشر شده‌اند.
